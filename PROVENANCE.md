# Provenance / Lineage Note

This v0.2 document preserves the following lineage:

1. Early ISQL:
   - attempted extreme semantic compression into a single infinite-precision scalar;
   - retained here only as historical motivation, not as the current engineering representation.

2. INSL:
   - replaced the single flat scalar with structured hierarchical sequences;
   - introduced context-dependent prefixes, expandable sequence structure, and reserved origin/root concepts;
   - this structural correction is retained.

3. SES / SPRC / Semantic Persona Runtime:
   - demonstrated that compact semantic codes + registry + seed + AI rendering can be implemented and replayed;
   - treated here as evidence that an executable ISQL domain is technically meaningful, not as the definition of ISQL Core.

4. ISQL Core v0.2:
   - moves the foundational question down to the code-base-space layer;
   - separates address, memory, semantics, state, and execution domains;
   - introduces multi-resolution recovery and decoder intelligence as explicit engineering variables.

No claim is made that the present code space is mathematically complete or that AI reconstruction is lossless.
