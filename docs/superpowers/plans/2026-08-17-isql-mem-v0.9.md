# ISQL-MEM v0.9 Locality Index and Automatic Base Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a rebuildable locality index and automatic actual-byte base selection for one-hop ISD8 memory deltas.

**Architecture:** Keep ISN7/ISD8 unchanged. Index standalone native frames with cheap block signatures, recall top-k deterministic candidates, then rerank by actually encoding ISD8 and select delta only when smaller than standalone.

**Tech Stack:** Python 3.11+, standard library only, unittest, JSON derived index.

## Global Constraints

- No new canonical wire format.
- Index is derived/rebuildable and never identity.
- Only standalone ISN7 frames may be bases.
- Actual encoded bytes decide the winner.
- No multi-hop delta chain.
- Existing v0.4-v0.8 frozen outputs remain byte-identical.
