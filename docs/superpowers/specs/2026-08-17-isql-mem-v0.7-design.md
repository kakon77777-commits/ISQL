# ISQL-MEM v0.7 — Machine-Native Canonical Representation Design

## Goal

Remove human-readable decimal text from the canonical ISQL memory path. The canonical machine memory artifact becomes a deterministic binary frame that directly binds stable address identity, registry revision/hash, resolution, and the spectral integer sequence.

## Core Decision

Human-readable forms are inspection/export views only.

$$
\boxed{\operatorname{DebugRender}(C)\neq C}
$$

The v0.7 canonical memory object is:

$$
\boxed{C_{\mathrm{native}}=(V,D,R,A,H,\mathbf z)}
$$

where:

- $V$ is native protocol version;
- $D$ is frame/domain kind;
- $R$ is memory resolution;
- $A$ is the raw 256-bit stable address digest;
- $H$ is the raw 256-bit spectral registry hash;
- $\mathbf z$ is the spectral integer coordinate sequence.

## Compatibility

v0.4 numeric memory wire, v0.5 registry numeric wire, and v0.6 packed decimal carriers remain supported but are legacy/inspection/transport profiles. They must not change byte-for-byte.

The existing `ISQLCode` textual address remains a compatibility/debug view. Native frames store the 32-byte digest directly.

## Binary Frame

Magic: `ISN7`

Fields:

1. magic: 4 bytes;
2. version: 1 byte, value 7;
3. kind: 1 byte, spectral memory = 1;
4. resolution: 1 byte, R1 = 1, R2 = 2;
5. flags: 1 byte, v0.7 requires zero;
6. address digest: 32 bytes;
7. registry revision: canonical unsigned varint;
8. registry hash: 32 bytes;
9. sequence item count: canonical unsigned varint;
10. block-packed spectral sequence;
11. CRC32: 4 bytes over every preceding byte.

## Integer Stream

The sequence is divided into blocks of at most 16 integers.

For each block:

1. one byte stores bit width $w$;
2. block values are packed densely using exactly $w$ bits each;
3. $w=0$ is valid only when every value in the block is zero;
4. unused padding bits in the final byte must be zero;
5. decode rejects overlong, truncated, non-canonical, or non-zero padding encodings.

This avoids decimal rendering and avoids a single unbounded bigint conversion.

## Stable Address Bridge

Existing address payloads represent a SHA-256 digest as decimal text. v0.7 provides deterministic bridges:

$$
\text{decimal debug address}\leftrightarrow\text{32-byte native digest}
$$

The raw digest is canonical in native frames; decimal is only an external view.

## Registry

The v0.5 hierarchical registry structural binary is already machine-native. v0.7 promotes the structural binary path as the canonical registry-delta transport and no longer requires its decimal registry wire for the native path.

Native memory decode must verify the referenced spectral registry revision and hash before expanding coordinates.

## APIs

```python
encode_native_spectral_frame(address, packet, resolution) -> bytes
decode_native_spectral_frame(frame) -> NativeSpectralFrame
compile_native_memory(record, resolution="R2") -> NativeMemoryCompileResult
expand_native_memory(frame, spectral_registry_store) -> SemanticCoordinateSet
inspect_native_frame(frame) -> dict
render_native_debug(frame) -> str
```

`render_native_debug()` is explicitly non-canonical.

## CLI

```text
isql-core native-compile --record ... --resolution R2 --out memory.isql7
isql-core native-decode --store ... --input memory.isql7
isql-core native-info --input memory.isql7
isql-core native-debug --input memory.isql7
```

## Invariants

1. Native encode/decode is deterministic.
2. `encode(decode(frame)) == frame`.
3. Address digest is preserved exactly.
4. Registry revision/hash is preserved exactly.
5. Expanded semantic coordinates equal the source spectral packet coordinates.
6. No native encode/decode path calls decimal numeric-wire encode/decode.
7. Existing numeric and carrier artifacts remain byte-for-byte unchanged.
8. Unknown version/kind/resolution, checksum mismatch, truncation, non-canonical varint, invalid width, and non-zero pad bits fail closed.
9. Human readability is not a design requirement.
10. Debug render output is never used for identity, replay, or hashing.

## Release Target

Package version: `0.7.0`.

The live release experiment must compare:

- v0.4 ASCII numeric memory wire;
- v0.6 D40 carrier;
- v0.7 native memory frame;
- coordinate round-trip fidelity.

The native frame is considered successful if it removes the decimal intermediary, preserves semantic fidelity exactly, and is no larger than the D40 carrier on the frozen R2 fixtures.
