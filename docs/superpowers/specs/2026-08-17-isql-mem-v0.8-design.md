# ISQL-MEM v0.8 — Locality Delta Frames and Random-Access Decode

**Status:** Approved design for implementation  
**Date:** 2026-08-17  
**Base:** ISQL Core Runtime v0.7.0

## Goal

Exploit locality between nearby AI memories without changing v0.7 machine-native canonical semantics, and allow block-level partial decode without materializing a full coordinate sequence.

## Core decision

v0.8 adds a second machine-native frame kind:

- `ISN7`: standalone native spectral memory, unchanged.
- `ISD8`: one-hop locality delta referencing exactly one standalone `ISN7` base.

No recursive delta chains are canonical in v0.8.

$$
\boxed{\text{base ISN7} + \text{ISD8 delta} \rightarrow \text{target spectral coordinates}}
$$

## Delta block model

Coordinates remain grouped into 16-item logical blocks. For each target block, the encoder deterministically chooses one mode:

1. `COPY`: target block equals base block; payload length zero.
2. `DELTA`: same block length; store signed coordinate differences using zigzag + canonical uvarints.
3. `REPLACE`: store the target block using the existing v0.7 bit-packed unsigned block representation.

Canonical choice:

- `COPY` whenever exact equality holds.
- otherwise `DELTA` only when its encoded payload is strictly smaller than `REPLACE`.
- ties choose `REPLACE`.

## ISD8 frame

Logical fields:

$$
C_{\Delta}=(V,R,A,B,G,Q,\mathcal D)
$$

where:

- `V`: delta protocol version;
- `R`: resolution;
- `A`: target stable-address digest;
- `B`: SHA-256 of the exact base `ISN7` frame;
- `G`: target registry binding, inherited from base unless explicitly overridden;
- `Q`: target sequence item count;
- `D`: per-block mode directory and payloads.

The frame is binary canonical data. Human-readable rendering is inspection-only.

## Registry inheritance

If the target registry revision/hash equals the base frame, ISD8 omits them and inherits the base binding. If they differ, ISD8 stores an explicit target revision/hash override. Spectral registry IDs remain append-only, so older IDs remain meaningful under later revisions.

## Random access

v0.8 exposes:

- native block indexing for `ISN7` without fully decoding the sequence;
- delta directory indexing for `ISD8`;
- `decode_delta_block(delta, base, index)` to reconstruct one target block only;
- block range decode for contiguous blocks.

The implementation may scan lightweight block headers/directories, but must not unpack unrelated coordinate payloads.

## Locality compiler

`compile_locality_memory(base_frame, target_record, resolution)` produces both:

- target standalone `ISN7` frame;
- candidate `ISD8` frame.

It selects delta only when:

$$
|ISD8| < |ISN7|.
$$

Otherwise it returns standalone native mode. This prevents locality machinery from making storage worse.

## Integrity and fail-closed rules

ISD8 must reject:

- wrong base-frame SHA-256;
- base that is not canonical `ISN7`;
- unsupported resolution;
- truncated directory/payload;
- invalid block mode;
- noncanonical uvarint/zigzag encoding;
- `COPY` whose target is not identical to base;
- `DELTA` when replace would be equal/smaller;
- `REPLACE` when copy/delta is canonically better;
- registry inheritance/override mismatch;
- nonzero padding;
- trailing bytes;
- CRC mismatch.

## Compatibility

v0.8 is additive. The following frozen artifacts remain byte-for-byte unchanged:

- v0.4 numeric memory wire;
- v0.5 registry numeric wire;
- v0.6 IPC6/D40 carrier;
- v0.7 ISN7 native frames.

## Initial experiments

1. Frozen memory #1 → #2: same typed coordinates, different stable address. Expected: COPY-heavy delta.
2. A synthetic near-neighbor target using only existing registry vocabulary. Expected: COPY/DELTA mixture.
3. Frozen memory #3 with registry growth. Expected: compiler may choose standalone if override + changes erase locality benefit.
4. Random block decode must equal the corresponding block of a full target decode.

## Non-goals

- unbounded delta chains;
- automatic nearest-neighbor search;
- learned vector locality;
- cross-registry ID remapping;
- mutable stable addresses;
- human-readable canonical frames.
