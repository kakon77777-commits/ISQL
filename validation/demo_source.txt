ISQL-MEM v0.2 treats memory as a representation layer rather than as object identity. The exact UTF-8 source receives a stable ISQL-ADDR code derived from its bytes. That address must remain stable even when an AI later rewrites, summarizes, expands, or reclassifies the memory. A memory record can therefore contain more than one profile under the same address. The baseline profile is deterministic and preserves the v0.1 preview, keyword, sentence-head, normalized-text, and exact-source hierarchy. The semantic profile stores an AI-assisted coordinate view without replacing the baseline. R0 is a locator and does not attempt reconstruction. R1 carries a compact gist, concept anchors, intent, tags, and language. R2 carries typed semantic coordinates including concepts, entities, relations, claims, uncertainty, and intent. R3 keeps normalized source text together with semantic provenance so richer reconstruction can still be audited. R4 retains the exact-source contract and is the only layer that may declare exact recovery when the original source is present. An AI analyzer must disclose its analyzer identifier and analysis contract. An AI decoder must disclose its decoder identifier and decoder contract. Neither analyzer nor decoder may modify the stable source address. Semantic recovery and exact recovery are intentionally different success conditions. Token overlap is useful as a transparent baseline metric but is not treated as semantic truth. Coordinate fidelity is therefore measured separately over concepts, entities, relations, claims, and intent. The first implementation uses exact normalized coordinate labels rather than embeddings so the score is reproducible and inspectable. Future versions may add learned similarity metrics as derived evidence, but they must not silently redefine canonical identity. Profile comparison also reports serialized layer size so compression and recoverability can be examined together. A smaller representation is not automatically better if it destroys required information. Likewise, a larger representation is not automatically better if the decoder can recover the same required semantics from fewer coordinates. The purpose of v0.2 is to make this tradeoff measurable. 這一層同時保留 UTF-8 多語言來源，地址仍然只由 exact bytes 決定。 The resulting architecture allows the same memory object to be tested across deterministic and AI-assisted encoders while keeping one immutable identity anchor.
